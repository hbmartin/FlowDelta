# 0.3.2 review fixes

Date: 2026-11-27

FlowDelta 0.3.2 fixes the eight defects that review of PR #4 found after 0.3.1 was tagged. The 0.3.1 tag (`0683d96`) stays where it is, and GitX pins 0.3.2 instead. The public API only gains members: `SourceEntity.declarationHeader` and `hasSameDeclarationHeader(as:)`, and four `LanguageBindingRules` properties. Some existing values now describe a change more strictly; see "Behavior hosts can observe".

## Fixes

### Noise

- Swift `self.` is no longer optional syntax. A parameter or local can shadow a property, so `return self.x` → `return x` can read a different value. Before, Hide Cosmetic hid that edit. No built-in language has an optional receiver now; `LanguageNoiseRules.optionalReceivers` stays for a host's own rules.
- JSX text is a literal for JavaScript and TypeScript and compares as React renders it:
  - spaces within a line stay, so `<pre> a </pre>` → `<pre>a</pre>` is a modification;
  - whitespace touching a line break and lines left empty drop out, so reindenting JSX content is still no change.

### Matching and grouping

- Entities carry `SourceEntity.declarationHeader`: the declaration's tokens outside its name, body and comments, with literals compared by exact text. It holds keywords, modifiers, effects, parameters, results and inheritance. It is empty when a declaration is its own body, such as a Swift top-level binding, and nil in reports made before 0.3.2. An unknown header matches any header.
  - The matcher reports a same-name entity as modified when its header changes, even if its body stays. Before, `def f()` → `async def f()`, a new Swift `async` or a new conformance was unchanged.
  - A rename or move is refactoring only while its header stays too, so `def before()` → `async def after()` is behavioral.
  - A modified entity whose header changed is behavioral, even when its body change is only noise.
- A type's own tokens compare literals by exact text. A field's initial value changing inside quotes, such as `text = " a "` → `text = "a"`, is now the type's own behavioral change. Before, it made the type a container in the refactoring concern.

### Data flow (Python and Go)

- Go declarations end with their block. A binding is a name plus the scope that declares it:
  - `:=`, `var` and `const` declare in the innermost block, case clause, or `if`, `for` or `switch` header;
  - an assignment updates the innermost binding that reaches it;
  - a binding ends at nodes outside its scope (the node after a loop is outside the loop), and the binding it shadowed reaches again.

  So in `func f(x int) int { if x := 1; x > 0 { use(x) }; return x }` the return reads the parameter. Python keeps one scope per function, so its results are unchanged.
- A Python nested `def` or `class` reads what Python evaluates when the definition runs: decorators, default values and base classes. Its body, parameter names and annotations are still not read.
- Go array and slice literal keys (`[]int{k: 1}`, `[4]int{k: 1}`, `[...]int{k: 1}`) are read as index expressions. Struct field labels still are not variables.

### Git

- Cancelling a comparison sends git SIGTERM, then SIGKILL if git is still running two seconds later, and logs the escalation. Before, a git or wrapper that ignored SIGTERM after closing its output kept the cancelled comparison waiting. The waiting caller reaps the process, and normal completion is unchanged.

### CI

- The workflow's Coverage step sets `TEST_RUNNER_CI=true`, because `xcodebuild` passes only `TEST_RUNNER_` variables to tests. The AppKit image snapshot then skips there as intended, and it is still verified on the recording host.
- The CLI command is built in the `FlowDeltaCommandLine` library, so CI's Xcode can test it.
- Two tests cover what only the snapshot reached, and call-graph enrichment, so CI's coverage holds its floor with the snapshot skipped.

## Behavior hosts can observe

- More entities are `modified`, each with a function delta, where only the declaration header changed. Triage, summaries and exports count them.
- Swift `self.` edits and JSX text edits are never hidden by a noise policy.
- Go def-use edges follow block scopes, so some edges move to the binding a declaration shadowed, and Python nested definitions gain edges into their decorators, defaults and bases.
- JSON reports include `declarationHeader` for each entity.
